# Modo Automatización — índice para implementación

> Documento de feature. `CLAUDE.md` sigue siendo la fuente de verdad del
> proyecto y prevalece ante cualquier contradicción.

Esta carpeta especifica el MVP del tercer modo de TYPELY: un sandbox de
automatización por bloques, visual y con temática de cristales.

## Leer en este orden

1. [`MVP.md`](MVP.md) — intención, experiencia, reglas y alcance.
2. [`IMPLEMENTACION.md`](IMPLEMENTACION.md) — arquitectura, estados, entregables
   y criterios de aceptación.

## Mandato central

No convertir este modo en un curso ni en una campaña de ejercicios. El chico
aprende porque un programa mejor le permite cosechar más cristales con menos
intervención. La economía y el mundo enseñan; el texto solo es respaldo.

## Decisiones vigentes

- Nombre interno: **Modo Automatización**; nombre comercial pendiente.
- Tema: cristales de distintos colores y formas.
- Vehículo: la nave que el alumno ya tiene en TYPELY.
- Dispositivo principal: Chromebook táctil en horizontal.
- Balance numérico: provisional y centralizado para playtesting.
- Esta rama contiene documentación solamente.
